# Modern Data Engineering · <span dir="rtl">هندسة البيانات الحديثة</span>

**SDAIA Academy · AI Engineering Track**: a 4-day hands-on bootcamp plus a capstone presentation day, for fresh CS graduates who want a bridge into industry. From raw sources to a tested, governed lakehouse with DuckDB, dlt, Polars, dbt, Pandera, Dagster, Apache Iceberg and Spark.

**Course page:** https://sdaiaacademy.github.io/data-engineering/

| Day | Theme | Sessions |
|---|---|---|
| [1](https://sdaiaacademy.github.io/data-engineering/slides/day1.html) | Store & Query | the job and the platform · analytical SQL with DuckDB · window functions · files for analytics |
| [2](https://sdaiaacademy.github.io/data-engineering/slides/day2.html) | Ingest & Clean | batch ingestion by hand · ingestion with dlt · changes and history · bronze to silver with Polars |
| [3](https://sdaiaacademy.github.io/data-engineering/slides/day3.html) | Model & Test | dimensional modeling · dbt · data quality · orchestration with Dagster |
| [4](https://sdaiaacademy.github.io/data-engineering/slides/day4.html) | Scale & Production | lakehouse with Iceberg · Spark · streaming · governance + capstone kickoff |
| [5](https://sdaiaacademy.github.io/data-engineering/slides/day5.html) | Capstone Project Presentations | team demos, technical Q&A, peer review |

Each day has four sessions, each about 20–25 minutes of concepts and demos, then a 25-minute lab.

The whole week follows one case study: **Qafila**, a fictional quick-commerce grocery platform in Riyadh, Jeddah and Dammam, with synthetic data generated by `labs/prepare_data.py`. One customer, Khalid, and one order, 5043883, run through every day. The decks draw the platform as it grows on hand-drawn boards.

Teams of 2–3 present a working platform on Day 5 and submit a public GitHub repository link: see [labs/capstone](labs/capstone/README.md).

## How the course is organised

Prerequisite: Python and basic SQL (SELECT, JOIN, GROUP BY). Every other term is defined when it is first used. Embeddings, vector search and LLMs are left to the Applied NLP course.

Longer tool walkthroughs (`labs/tools/`, `labs/demos/`) are optional reading linked from the course page; no session or lab depends on them.
